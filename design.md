# Abdul Saboor's Portfolio — Design Breakdown

## Overall Aesthetic

The portfolio uses a **dark, deep navy/near-black background** (`#0a0f1e` range) with a subtle blue gradient glow effect, giving it a premium, futuristic feel. The color palette is minimal: dark backgrounds, white text, and a signature **cyan-to-blue gradient accent** used for highlights, buttons, and key words. Typography is bold and oversized for headings, clean and readable for body text.

---

## Section-by-Section Layout

### 1. Navigation Bar
- Sticky top navbar with a frosted/dark pill-shaped container on the left showing the **"AS" avatar + name**
- Right side has flat text nav links: About, Skills, AI Lab, Work, Journey, Contact
- Clean, minimal — no borders, just spacing
- A **"Let's Talk" CTA button** appears in some scroll states (teal gradient pill)

---

### 2. Hero Section
- **Status badge** at the top center — a small capsule reading "● AVAILABLE FOR NEW PROJECTS" with a glowing dot
- Massive display heading split across three lines:
  - "Building the" (white)
  - "**agentic web**" (cyan gradient)
  - "one system at a time." (white)
- Sub-headline introduces the person: bold name + role description
- Two CTA buttons: **"View selected work →"** (solid teal/blue gradient) and **"✦ Hire me"** (dark outlined)
- Two icon buttons (GitHub and LinkedIn) beside the CTAs

---

### 3. Stats Bar
- A horizontal card with 4 equally spaced metrics in a dark rounded rectangle:
  - **3+ yrs** — Web Development
  - **1+ yr** — Vibe / AI Coding
  - **20+** — AI Agents Shipped
  - **∞** — Curiosity Index
- Numbers are large cyan, labels are small uppercase grey text

### 4. About Section
- Left column: section label `// ABOUT`, bold headline "A developer who treats agents **like teammates**." (cyan gradient on key words)
- Two paragraphs of body text below
- Right column: **2×2 grid of service cards**, each with:
  - A small icon in a blue-tinted square
  - Bold title

  Cards: Full-Stack Engineering, Agentic AI, Automation, Backends & Data

### 5. Skills / Stack Section
- Section label `// STACK`
- Large heading: "Tools that **compose** into products."
- Subtext on the right explaining the stack philosophy

### 6. AI Lab Section

- Large heading: "Agents, employees & assistants — **deployed**." (cyan gradient on "deployed")

  - Icon with blue gradient background
  - Bold title + colored status badge (TRENDING, PRODUCTION, WORKFLOWS, TOOLING)

### 7. Work / Projects Section
- Section label `// SELECTED WORK`
- Heading: "Projects that **ship**." (cyan on "ship")

  - Small colored category label (AGENTIC AI, FULL-STACK + AI, etc.)
  - Bold project title
  - Short description
  - Tech stack pill tags at the bottom
  - Arrow icon (↗) in the top-right corner

### 8. Journey Section
- Section label `// JOURNEY`
- Heading: "From **first commit** to **autonomous agents**." (cyan gradient on key words)

  - Right card: Freelance & Personal Projects (2023–Present), role subtitle in cyan, description card
  - Left card: Currently pursuing BSc Computer Science
- Timeline dots are cyan circles on the center line

---

### 9. Contact Section
- Section label `// CONTACT`
- Left column: "Let's build something **intelligent**." heading, short CTA text
- Contact info cards (email, location) in dark bordered rectangles with icons
- GitHub and LinkedIn buttons side by side
- Right column: **Contact form** with fields:
  - Name, Email (side by side)
  - Subject
  - Message (textarea)
  - **"Send message"** button — full-width cyan-to-blue gradient

---

### 10. Footer
- Simple dark footer with a thin top border
- Left: AS avatar + full name + one-liner bio
- Center: Location and email with small icons
- Right: GitHub and LinkedIn icon buttons
- Bottom center: copyright line — "© 2026 Abdul Saboor Arif. Crafted with intent in Karachi."

## Design System Summary

| Element | Style |
|---|---|
| Background | Deep navy `#080d1a` with blue glow |
| Primary accent | Cyan → blue gradient |
| Headings | White, extra-bold, very large |
| Body text | Light grey, regular weight |
| Cards | Dark navy with subtle border, rounded corners |
| Buttons | Gradient fill (primary) or dark outlined (secondary) |
| Tags/Pills | Dark background, small rounded, no fill |
| Section labels | Small, spaced uppercase, cyan — prefixed with `//` |
